Step 2Your first real run

follow in

A real run calls a model. The model is named once, as default_model: in hello/team.yaml: teamrunner/demoLLM, a small model we host so that your first runs need no account and no key, at no charge to you. It answers up to 100 requests a day from each address (a run of hello takes three), with short replies; past that it says so, and the run stops. Your prompts go through our gateway to the demo's model provider, currently Anthropic, so do not send it anything private. Step 7 moves to a model of your own choosing.

Select team.yaml to see it. Then run it for real: choose Run…, clear Rehearse (free, no model) and choose Run with models. The conversation appears as it happens, and the judge's verdict at the end.

explain shows it beside each member:

teamrunner explain hello

Run it for real:

teamrunner run hello

Run it again, and this time give it your own topic: in Run…, choose A message under What to give the team and type Four-day weeks make teams more productive. The message fills in {{topic}}. Tick Rehearse (free, no model) to try a message for free.

Run it again, and this time give it your own topic. --message fills in {{topic}}:

teamrunner run hello --message "Four-day weeks make teams more productive"

You can rehearse with a message too, for free:

teamrunner run hello --rehearse --message "Four-day weeks make teams more productive"

Every run is kept in hello/runs/, one folder each, named for when it ran. Its output.md is what the team produced. Next to it, events.jsonl holds every turn, with every prompt, reply, model, token and cost.

Run history lists them, newest first, with each verdict. Select one to read its Conversation, its Output and its Record; the links beside them open the files themselves.

Open the newest one's output.md in your text editor. To list the runs, newest first, with each verdict:

teamrunner runs hello

And to see the newest one again, as it printed:

teamrunner runs hello latest

Another provider, or free local models? Change default_model: to openai/…, anthropic/… or gemini/… and add that provider's key, as step 7 shows. Free models on your own computer work too, through Ollama: ollama/gpt-oss:20b. Pick one of about 20 billion parameters or more: the smallest models often can't give answers in the form a team needs.

Or describe a team in a sentence, and a model writes the files for you. It needs a model key of your own (step 7 shows how to add one), and the provider charges for it; the cost varies. You can rehearse what it wrote for free. In a terminal:

teamrunner new launch --describe "A product manager pitches a feature. An engineer and a designer push back, twice. Then the CEO decides go or no-go."
