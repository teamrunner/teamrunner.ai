Data destinations and local records

Requests to hosted models transmit the selected prompts, conversation context, and supplied content to the configured API endpoint using your configured models and credentials. Provider terms and data practices apply. A local model can process model requests locally, but configured tools and downloads can still contact external services.

The sponsored demo sends prompts and conversation context through the gateway operated by Serenity Partners LLC, then OpenRouter and its upstream model provider. The gateway processes requests and responses and stores IP-based quota counters to enforce usage limits. The supplied gateway configuration does not log prompt/response bodies or API keys; this is not a promise about upstream provider logging, retention, or training practices. Do not submit private, confidential, sensitive, or regulated information to the demo.

The local client does not send separate usage telemetry to the publisher. That does not mean it makes no network requests: model APIs, the demo gateway, web tools, provider model-list checks, runtime/package downloads, diagram assets, and configured integrations can contact their respective services.

Local run folders can retain prompts, supplied files, outputs, retrieved content, and other sensitive information. Review and redact records before sharing them, and avoid placing secrets in prompts or team files.

Website data

This website is hosted on GitHub Pages. Page visits and selected actions are counted through GoatCounter without analytics cookies. The site loads font styles and files from Google Fonts. Those services receive network requests and have their own data practices; this is not a promise of anonymous browsing.

News signup sends your email address and the signup page to a Google Apps Script service operated for TeamRunner. It stores the address, signup time and page in our Google Sheet. We use the list for TeamRunner updates. Every update has an unsubscribe option; email hello@teamrunner.ai to request removal.

The recorded debates on the homepage are replays, not live model calls. Their original records retain the file names and cost estimates from the version that produced them. Running a team locally can send inputs to the services described above.
