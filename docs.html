Glossary

The words, in plain English

API key
A password-like code from a model provider that lets TeamRunner use its models. The provider bills you for what you use. Rehearsals need none.
chair
The file chair.md: the meeting’s script, saying who speaks when. With no chair, members take one turn each, in name order.
context
Everything a model reads before it answers: its instructions plus what has been said. Smaller is cheaper and usually steadier.
diff
A view of what changed between two versions of a file: removed lines in red, added lines in green.
frontmatter
The settings block between the two --- lines at the top of an agent’s file.
git
Version control: it keeps every saved version of a folder, so you can go back, see what changed, or share it. Optional.
Markdown
Plain text with light formatting, in a file ending .md. An agent is one.
rehearsal
A run with no model: placeholder words and random answers. Free, needs no key, and shows whether the flow goes where you meant.
replications
How many times each version is run. Models are random, so one run is an anecdote.
side trip
A member asking a toolkeeper during its own turn, when it chooses. Not a step in the flow; the answer goes to that member alone.
terminal
The window where you type commands: Terminal on a Mac, PowerShell on Windows.
toolkeeper
A member with no model that holds one tool, such as reading the web, and decides who may use it and how often.
uv
A single program that installs Python for you and runs Python tools, each in its own space. It is how we suggest installing TeamRunner.
YAML
A plain-text format for settings, one name: value per line. team.yaml is one.
