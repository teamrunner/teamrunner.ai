Example · hiring_committee

Every fact the committee needs is in the room. Does it find them?

In 1985 Stasser and Titus showed that human groups mostly discuss what they all already know, and so miss the facts that would change their decision. It is one of the most replicated findings about how groups decide. With TeamRunner you can ask whether a committee of AI agents falls into the same trap, and what gets it out. It ships as an example, so you can run it today.

The task

Three members, three candidates, and facts no one person has

The committee is hiring a Director of Operations for a food bank. Everyone has read the same packet, which makes Avery look best. Each member also holds two facts the others don’t, written into that member’s own file.

Alone, each member would still choose Avery. With all six facts on the table, Blake is the clear choice.

The change

Change how the meeting is run: swap one line for another

A well-known fix from the research is to have everyone report what they know before anyone gives an opinion. In TeamRunner the way a meeting runs lives in one file, chair.md. Both versions are already written there. Put a # in front of one and take it off the other. Nothing else changes.

chair.mdopen discussion → share first
# How the meeting is run. This is the line the experiment changes.
- meeting(*3) -> clerk:record
+ # meeting(*3) -> clerk:record
- # chen:share_facts -> diaz:share_facts -> okafor:share_facts -> meeting(*2) -> clerk:record
+ chen:share_facts -> diaz:share_facts -> okafor:share_facts -> meeting(*2) -> clerk:record
meeting = chen -> diaz -> okafor
Red is the old line, green the new one: this view of a change is called a diff. A line starting with # is a note for people, and is not run.
The run

Run both versions, a few times each, and compare

Every turn records whom each member would hire right now, so you can see when minds change and whose facts changed them. Models are random, so run each version more than once; teamrunner runs lists every run with the committee’s decision.

Running each version 25 times and getting one table takes one experiment.md: see tutorial part 2.

in your terminalworks today
teamrunner new open --from hiring_committee
teamrunner new share_first --from hiring_committee
# swap the line in share_first/chair.md, then:
teamrunner run open
teamrunner run share_first
teamrunner runs open
teamrunner runs share_first
